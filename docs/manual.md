# Manual

Carnaval Tic-Tac-Toe is a fun two-player game
that is best played during carnaval.

## Goal

Get three in a row (either horizontally, vertically or diagonally).

## Gameplay

The first player starts.
He/she needs to press the left mouse button on the 3x3 board
to place his/her symbol there.
After placing a symbol, it is the other player's turn.

## Questions

### The symbol for player 1 and player 2 is identical

This is correct.

This is to make sure the game is **realistic**:
during carnaval you will also have to remember which beer
is yours.

### The game does not detect 3 in a row

This is correct.

This is to make sure the game is **fun**:
you will have to decide who won or
decide that it is a draw.
